# Отчет по проверке тематических маршрутов блока «С чем я помогаю»

Дата проверки: 24.07.2026

## 1. Что проверено

Проверены тематические маршруты всех шести карточек блока «С чем я помогаю», их пересечение с существующими страницами сайта, canonical, Title, H1 и редиректы.

Особое внимание уделено:

- `/help/eating-disorders`
- `/rpp`
- `/help/grief-crisis`
- `/help/trauma-ptsd`

## 2. Найденные дубли

Обнаружен потенциальный SEO-дубль:

- `/help/eating-disorders`
- `/rpp`

Обе страницы относились к теме расстройств пищевого поведения. Для избежания двух индексируемых страниц с одинаковым смыслом каноническим маршрутом выбран `/rpp`, так как это уже полноценный раздел «Энциклопедия РПП» с расширенной структурой материалов.

## 3. Что исправлено

1. Карточка «Нарушения приема пищи и расстройства пищевого поведения» теперь ведет напрямую на `/rpp`.
2. Для `/help/eating-disorders` настроен постоянный редирект `301` на `/rpp`.
3. Страница `/help/eating-disorders` больше не генерируется как отдельный тематический маршрут.
4. Карточка про утрату и кризисы уточнена до темы: «Утрата, жизненные кризисы, психологическая травма и ПТСР».
5. Для `/help/trauma-ptsd` настроен постоянный редирект `301` на `/help/grief-crisis`.
6. Ссылка в навигации «Расстройства пищевого поведения» переключена на `/rpp`.
7. Ссылка в навигации «Травма и ПТСР» переключена на `/help/grief-crisis`.

## 4. Редиректы

| Старый URL | Новый URL | Тип |
|---|---|---|
| `/help/eating-disorders` | `/rpp` | 301 |
| `/help/trauma-ptsd` | `/help/grief-crisis` | 301 |

Проверено через `curl -I`:

```text
/help/eating-disorders -> 301 Location: /rpp
/help/trauma-ptsd -> 301 Location: /help/grief-crisis
```
