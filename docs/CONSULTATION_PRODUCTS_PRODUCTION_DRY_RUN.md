# Dry-run переноса модели продуктов на production

Дата подготовки: 19 июля 2026.

Этот документ описывает только безопасную проверку. Он не разрешает применять миграции, менять production-базу, перезапускать сайт или проводить платежи.

## Цель

Проверить, что новая модель `consultation_products` может быть перенесена на production без потери старых цен, записей, оплат, возвратов и клиентских пакетов.

## Что проверяет dry-run

- Наличие `DATABASE_URL` без вывода пароля.
- Доступность production PostgreSQL.
- Наличие старой таблицы `pricing_items`.
- Количество старых строк цен.
- Сопоставление старых строк с новыми продуктами:
  - `single-session` для одиночной консультации;
  - `package-7` для пакета 7 консультаций.
- Что helper не выполняет запись в базу.

## Команды только для проверки

Выполнять на сервере из папки проекта, после backup и только по отдельной команде владельца:

```bash
cd /var/www/luneva-platform
npx tsx scripts/migrate-consultation-products.ts
```

Проверка защитного блока write-mode:

```bash
npx tsx scripts/migrate-consultation-products.ts --apply
```

Ожидаемый результат: команда должна завершиться ошибкой `Write mode is blocked: pass --backup-confirmed after a verified backup.`

## Ожидаемая таблица сопоставления

Локальный dry-run нашел 4 старые строки:

| Старый тариф | Формат | Цена | Новый продукт | Действие |
|---|---|---:|---|---|
| Очно | Очно в кабинете | 7 000 руб. | `single-session` | Только чтение |
| Очно (пакет 7 сессий) | Очно в кабинете | 42 000 руб. | `package-7` | Только чтение |
| Онлайн | Онлайн | 7 000 руб. | `single-session` | Только чтение |
| Онлайн (пакет 7 сессий) | Онлайн | 42 000 руб. | `package-7` | Только чтение |

На production число строк нужно подтвердить заново.

## Stop conditions

Остановиться и не применять миграцию, если:

- `pricing_items` не читается;
- найдено не 4 строки или есть незнакомые тарифы;
- в production нет таблиц из миграций `0028` и `0029`;
- `DATABASE_URL` указывает не на ожидаемую production-базу;
- dry-run показывает неоднозначное сопоставление;
- есть незакоммиченные изменения, не относящиеся к переносу.

## Что запрещено в dry-run

- `npm run db:migrate`
- ручной запуск SQL-миграции;
- `--apply --backup-confirmed --allow-production`;
- изменение `pricing_items`;
- изменение старых `yookassa_payments`;
- изменение `yookassa_refunds`;
- реальные платежи или возвраты;
- перезапуск production.
